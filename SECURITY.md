# Security reports

Report security concerns privately through the [PRO-Webs helpdesk](https://prowebsinc.zohodesk.com/portal/en/newticket). Include affected versions, reproduction steps and sanitized technical details. Never include real customer data or credentials in a public issue.

Customer removal requires an authenticated admin session, permission to both Customers and Bulk customer removal, a valid security token, a reviewed selection and a one-use confirmation. The server determines the deletion set from its saved review, not from the final posted customer IDs. Keep Zen Cart and PHP within supported versions.
